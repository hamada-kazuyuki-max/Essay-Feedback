# 論述室 | 小論文 評価ワークスペース

課題文・設問・受験者の答案から、模範解答例、評価ルーブリック、採点・添削コメントを作成するブラウザアプリです。

## 起動

`index.html` をブラウザで開くだけで使えます。ビルドやパッケージのインストールは不要です。「サンプルを読み込む」で入力例を試せます。

## AI評価を有効にする

1. 画面右上の設定を開きます。
2. OpenAI互換のChat Completions APIエンドポイント、モデル名、APIキーを入力して保存します。
3. 課題文・設問・答案を入力し、「模範解答・基準・採点を作成」を実行します。

APIキーはブラウザのタブを閉じると消去し、ローカルには保存しません。課題文と答案は設定したAPI提供元へ送信されます。提供元のCORS設定によってブラウザからの直接接続が制限される場合は、CORSを許可したバックエンド経由での接続が必要です。APIキーを信頼できないエンドポイントに入力しないでください。

## デモモード

API未設定でもサンプルや評価画面を操作できます。デモの採点は文字数と表層的な表現による簡易判定で、答案の論旨や事実関係を理解しません。表示される点数は実際の採点に使用せず、AI評価を利用する場合も教員が最終確認してください。
